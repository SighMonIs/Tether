Firefox Extension

Save links to Tether directly from Firefox. Click the extension icon on any page to save the URL and assign tags.

  1. Download the extension folder from your server or copy firefox-extension/ from the Tether repo to your computer.
  2. Open Firefox and go to about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and select the manifest.json file inside the extension folder.
  4. The Tether icon will appear in your toolbar. Click it and open Settings.
  5. Enter your server URL and the API key shown below, then click Test connection.

Slash Commands

Type / in a note to open the command menu. Block commands (headings, lists, quote, code block, divider) also trigger directly if you type the full command and press space.

  • /heading1Heading 1
  • /heading2Heading 2
  • /heading3Heading 3
  • /bulletlistBullet list
  • /numberedlistNumbered list
  • /tasklistTask list
  • /quoteQuote
  • /codeCode block
  • /dividerDivider
  • /boldBold
  • /italicItalic
  • /underlineUnderline
  • /strikethroughStrikethrough
  • /inlinecodeInline code
  • /linkLink
