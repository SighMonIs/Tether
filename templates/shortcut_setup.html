Option A — Generate with AI (iOS 18+)

In the Shortcuts app tap + → New Shortcut, then tap the sparkle / wand icon to open the AI prompt. Copy the prompt below and paste it in.

Create a shortcut that appears in the Share Sheet and accepts any input. Make sure "Use as Quick Action" and "Show in Share Sheet" are enabled in the shortcut settings. Step 1: Get URLs from the shared input. Step 2: URL-encode the URLs magic variable from step 1. Step 3: Create a Text value equal to "{{ local_ip }}/?add=" followed by the URL-encoded text from step 2, with no space between them. Step 4: Open the URL from step 3 (this opens Safari on the Tether website with the link pre-filled, where you pick tags and save).

The AI may not get every detail right — check the actions it generates against the manual steps below and adjust where needed.

Option B — Manual setup

1
Open the Shortcuts app and create a new shortcut

Tap + in the top-right corner, then tap Add Action.

2
Add: Receive Input from Share Sheet

Search for Receive Input. Leave the input type as Any. This lets the shortcut accept links from any app, including TikTok and YouTube which share as text rather than URLs.

!
Enable "Show in Share Sheet" — do this before building

Tap the shortcut name at the top to open its settings, then tap Add to Share Sheet (or toggle Show in Share Sheet). Without this the shortcut will never appear when you tap Share in other apps. You can do it now or after step 7 — just don't skip it.

3
Add: Get URLs from Input

Search for Get URLs from Input. This extracts a clean URL from whatever was shared — even if the app passed it as text. The input should be Shortcut Input from step 2.

4
Add: URL Encode

Search for URL Encode. Set the input to URLs (from step 3) and leave the mode as Encode. This escapes any & or ? in the shared link so it survives being placed inside another URL.

5
Add: Text

Search for Text. Set its content to:

{{ local_ip }}/?add= followed immediately by the Encoded URL magic variable (from step 4) — no space in between
6
Add: Open URLs

Search for Open URLs. Set the input to the Text magic variable from step 5. This opens Safari on the Tether website with your link pre-filled, where you'll see the page title, description, and can pick tags and add a note before saving.

7
Name and save

Tap the shortcut name at the top and rename it to Tether. Tap Done. It will now appear in your Share Sheet.

How to use it

1
Open any page you want to save

Works in Safari, YouTube, Reddit — anywhere with a Share button.

2
Tap Share → Tether

Scroll down in the Share Sheet until you see Tether.

3
Safari opens on Tether with the link ready

Pick your tags, add a note if you want, and hit Save. Your phone must be on the same Wi-Fi network as the server.
